# 工E千程

一个可直接打开的 Web-first 竞赛作品原型：在重要人生选择之前，用逐月现金流和 1,000 次情景模拟，让用户看见不同选择可能把未来带到哪里，并用资金配置实验室把结果转成安全垫、近期目标、成长预算和机动余额。

## 运行

直接双击 `index.html`，或在当前目录启动任意静态文件服务器。当前版本是面向下一阶段迭代的参考原型：选择一个人生方向 → 保留一句话需求 → 点击“识别并模拟” → 切换“安全优先 / 平衡成长 / 目标加速” → 点击路线节点查看目标支出与 P10/P50/P90。

## 目录中的核心文件

- `index.html`：单页产品工作台。
- `app.js`：现金流模拟、路线图、概率带和节点事件。
- `app-enhance.js`：五类人生方向、需求画像和目标事件。
- `asset-lab.js` / `asset-lab.css`：资金配置实验室及三种策略；策略会进入模拟引擎的支出与压力事件参数。

## 作品边界

- 页面上的账户、流水与模拟结果均为虚构演示数据。
- 70 人调查为小样本探索性调查（N=70），不代表全国性结论。
- AI 的产品定位是语言结构化与结果解释，不负责生成金额、概率或替用户做决定。
- 资金配置实验室不推荐具体金融产品，只展示资金用途、安全边界和用户选择的后果；金融服务入口由用户主动触发。
- 本版本使用浏览器内的轻量、可复现模型演示交互；后续可将计算模块替换为 FastAPI + NumPy 服务，并在正式落地前完成真实数据校准、模型验证和合规评估。

# 工E千程

工E千程是一款面向高校学生的财务情景模拟原型。用户可以比较校园消费、城市就业、继续深造、创业、自由职业和家庭安排，查看这些选择对未来现金流的影响。

## 运行

在项目目录启动静态服务器后打开网页：

```powershell
python -m http.server 4174
```

浏览器访问 `http://localhost:4174`。选一个人生方向，修改输入条件后生成路线；再切换资金策略、点击路线节点，查看目标支出前与期末资金的变化。

## 目录中的核心文件

- `index.html`：单页产品工作台。
- `app.js`：现金流模拟、路线图、概率带和节点事件。
- `app-enhance.js`：五类人生方向、需求画像和目标事件编排。
- `decision-engine.js`：固定种子的逐月情景现金流模拟、共用随机扰动路线对照，以及五因素 Shapley 反事实归因。
- `asset-lab.js` / `asset-lab.css`：资金配置实验室及三种策略；策略会进入模拟引擎的支出与压力事件参数。

## 路线差异归因

- 每条路线运行 1,000 条、最长 120 个月的现金流路径；界面默认观察 36 个月。输入和随机种子一致时，输出可复现。
- A/B 与反事实情景共用同一组收入波动、支出扰动、突发支出和收入中断抽样，减少路线比较时由随机抽样带来的噪声。
- 将差异拆为收入与入职时点、住房与日常成本、大额目标与时点、家庭现金流、收入波动与风险五组因素。枚举 32 个因素组合，按 Shapley 边际贡献分解目标前可用资金与期末资金差异。
- 复现参数：固定种子 `170017`；收入采用路线波动率控制的正态扰动（乘数下限 0.1），支出采用标准差 0.09 的正态扰动（乘数下限 0.25）；月度突发支出概率为 `min(0.35, 0.006 + 风险等级×0.0017 + 路线风险溢价)`，发生时金额为 `¥1,200 + U(0,1)×风险等级×¥900`。
- “目标前可用资金”在目标月扣款前测量，并先扣除同月发生的其他目标支出；若同名同金额路线支出正是当前目标，则只计一次，防止目标预算被重复扣除。
- 归因是当前演示假设下的模型解释，不是因果识别，也不代表经真实用户数据校准的预测概率；参数和分布仍需真实数据校准与验证。

## 本地验证

在项目目录运行 `node --test tests/decision-engine.test.cjs`，覆盖固定种子复现、同扰动公平对照、目标时点现金流变化、Shapley 加总一致性及收入/住房敏感性。

## 作品边界

- 页面上的账户、流水与模拟结果均为虚构演示数据。
- 70 人调查为小样本探索性调查（N=70），不代表全国性结论。
- 当前版本使用本地关键词规则整理输入，尚未接入生成式 AI。金额和概率由现金流模拟引擎计算，规则识别与模拟结果都可以检查。
- 资金配置实验室不推荐具体金融产品，只展示资金用途、安全边界和用户选择的后果；金融服务入口由用户主动触发。
- 本版本使用浏览器内的轻量、可复现模型演示交互；后续可将计算模块替换为 FastAPI + NumPy 服务，并在正式落地前完成真实数据校准、模型验证和合规评估。
